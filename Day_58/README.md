# Deployment Strategy Study

Date: 2026-04-24
Track: DevOps and CI/CD Foundations

## Focus
The learning focus was deployment strategies and rollout safety in DevOps workflows. The goal was to understand how production releases can be introduced gradually and safely instead of replacing everything at once.

## Topics Covered
- Why deployment strategy matters after CI succeeds
- Difference between direct deployment and controlled rollout
- Blue-green deployment basics
- Canary deployment thinking for gradual traffic shift
- Importance of health checks during rollout
- Rollback readiness when a new version becomes unhealthy
- Tradeoffs between speed, safety, and operational complexity

## Practical Work Completed
- Built a deployment rollout simulation comparing staged release behavior
- Built a health-check and rollback simulation for failed deployment detection
- Observed how gradual rollout reduces release risk
- Compared all-at-once deployment mindset against controlled traffic movement

## Takeaway
This learning session improved DevOps thinking around production safety, release confidence, and rollback planning. It strengthened readiness to understand deployment workflows beyond simple code delivery.
