# 📅 Day 1 – Project Setup (portfolio-evaluator)

On the first day, the primary objective was to initialize the MERN monorepo project named **portfolio-evaluator** and ensure that the folder structure strictly followed the given specifications. The project was organized into two main directories: **client** and **server**, representing the frontend and backend respectively.

The client-side setup was completed using React with Vite. A new Vite project was created inside the `client` directory, and all required dependencies were installed. After the initial setup, the default boilerplate code was cleaned to keep the project minimal and organized. Within the `src` folder, three essential directories were created: `components`, `pages`, and `utils`. These folders will help maintain a clean separation of concerns for reusable UI components, page-level views, and utility functions as the project progresses.

On the server side, a Node.js project was initialized inside the `server` directory using npm. Express was installed as the core framework for building the backend API. Instead of adding any logic, the focus was on structuring the backend properly. The directories `controllers`, `routes`, `services`, `models`, `middleware`, and `config` were created to ensure a scalable and maintainable architecture. Each of these folders will later handle specific responsibilities such as request handling, routing, business logic, database schemas, middleware functions, and configuration settings.

Throughout the setup process, strict attention was given to following the exact folder structure provided in the requirements. Separate `package.json` files were maintained for both the client and server to ensure independent dependency management. No business logic or functional implementation was added at this stage, as the goal was purely to establish a clean and well-organized foundation for future development.

By the end of the day, the MERN monorepo structure was successfully created, with both frontend and backend environments properly initialized and ready for further development in the upcoming phases.
